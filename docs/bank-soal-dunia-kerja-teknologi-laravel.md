# Bank Soal — Dunia Kerja, Teknologi, dan Laravel

**Materi sumber:** [`workshop-laravel-smkn2-tbn/dunia-kerja-teknologi-laravel.html`](workshop-laravel-smkn2-tbn/dunia-kerja-teknologi-laravel.html)

**Petunjuk:** Pilih satu jawaban yang paling tepat. Setelah menjawab, cocokkan dengan kunci, lalu baca penjelasan untuk jawaban benar dan salah.

### Soal 1 — Dunia Kerja

Menurut materi, kemampuan yang dibutuhkan dunia kerja dibagi menjadi tiga kelompok. Manakah pembagian yang tepat?

- **A.** Skill teknis, skill manusia, dan bukti kemampuan
- **B.** Skill teknis, hobi, dan keberuntungan
- **C.** Ijazah, nilai rapor, dan sertifikat
- **D.** Skill membaca, menulis, dan menghitung

**Kunci: A**

- ✅ **Jika benar:** Materi membagi menjadi skill teknis (programming, database, web, cloud, testing, version control), skill manusia (komunikasi, disiplin, kolaborasi, berpikir kritis, bahasa Inggris), dan bukti kemampuan (portfolio, GitHub, project nyata, dokumentasi, pengalaman praktik).
- ❌ **Jika salah:** Ijazah dan nilai rapor memang membantu membuka pintu, tetapi tidak termasuk salah satu dari tiga kelompok pada materi.

---

### Soal 2 — Apa Itu Programming?

Apa definisi programming menurut materi?

- **A.** Mengetik kode secepat mungkin
- **B.** Memberi instruksi terstruktur kepada komputer untuk menyelesaikan masalah
- **C.** Menghafal semua sintaks bahasa pemrograman
- **D.** Memasang aplikasi di komputer

**Kunci: B**

- ✅ **Jika benar:** Programming adalah proses memberi instruksi terstruktur kepada komputer untuk menyelesaikan masalah. Programmer memahami masalah sebelum memilih kode.
- ❌ **Jika salah:** Kecepatan mengetik, hafalan sintaks, atau memasang aplikasi hanyalah bagian kecil dan bukan inti dari programming.

---

### Soal 3 — Apa Itu Programming?

Urutan kerja sebuah program yang benar adalah …

- **A.** Output → Process → Input
- **B.** Input → Process → Output
- **C.** Process → Output → Input
- **D.** Input → Output → Process

**Kunci: B**

- ✅ **Jika benar:** Data masuk (input) diproses melalui logika/aturan (process), lalu menghasilkan hasil (output). Urutan inilah yang dipakai saat form data siswa divalidasi lalu disimpan.
- ❌ **Jika salah:** Opsi lain membalik urutan sehingga alurnya tidak logis.

---

### Soal 4 — Jenis Teknologi

Bidang teknologi yang menangani server, deployment, container, monitoring, dan CI/CD adalah?

- **A.** Web
- **B.** Data & AI
- **C.** Cloud & DevOps
- **D.** IoT

**Kunci: C**

- ✅ **Jika benar:** Cloud & DevOps berfokus pada server, deployment, container, monitoring, dan CI/CD.
- ❌ **Jika salah:** Web berfokus pada website/aplikasi web, Data & AI pada analisis data dan machine learning, sedangkan IoT pada sensor dan perangkat pintar.

---

### Soal 5 — Jenis Teknologi

Teknologi yang berfokus pada proteksi akun, aplikasi, jaringan, dan data disebut?

- **A.** Cybersecurity
- **B.** Mobile
- **C.** Cloud & DevOps
- **D.** Web

**Kunci: A**

- ✅ **Jika benar:** Cybersecurity melindungi akun, aplikasi, jaringan, dan data, misalnya dengan hashing password, 2FA, serta HTTPS.
- ❌ **Jika salah:** Mobile berkaitan dengan aplikasi Android/iOS, Cloud & DevOps dengan server dan deployment, Web dengan situs dan aplikasi web.

---

### Soal 6 — Website

Bagian website yang dilihat dan berinteraksi langsung dengan user (HTML, CSS, JavaScript) disebut?

- **A.** Frontend
- **B.** Backend
- **C.** Database
- **D.** Deployment

**Kunci: A**

- ✅ **Jika benar:** Frontend adalah bagian yang dilihat user, dibangun dengan HTML, CSS, dan JavaScript.
- ❌ **Jika salah:** Backend menangani logika server, database tempat data disimpan, dan deployment adalah proses menjalankan aplikasi di server.

### Soal 7 — Website

Pada urutan belajar website di materi, tahap setelah backend adalah?

- **A.** Desain grafis
- **B.** Deployment
- **C.** Machine learning
- **D.** Aplikasi mobile

**Kunci: B**

- ✅ **Jika benar:** Urutan belajarnya: HTML → CSS → JavaScript dasar → database → backend → deployment.
- ❌ **Jika salah:** Desain grafis, machine learning, dan mobile adalah jalur lain yang tidak termasuk urutan belajar website pada materi.

### Soal 8 — Trend Web Development

Dalam perumpamaan restoran pada materi, API dianalogikan sebagai?

- **A.** Ruang makan dan menu
- **B.** Dapur dan koki
- **C.** Gudang bahan
- **D.** Pelayan

**Kunci: D**

- ✅ **Jika benar:** API seperti pelayan yang menyampaikan pesanan antara pengunjung (frontend) dan dapur (backend).
- ❌ **Jika salah:** Ruang makan/menu = frontend, dapur/koki = backend, dan gudang bahan = database.

---

### Soal 9 — Trend Web Development

Menurut materi, apa yang tetap menjadi fondasi walau framework berganti?

- **A.** Nama framework terbaru
- **B.** HTML, CSS, JavaScript, dan SQL
- **C.** Versi library JavaScript
- **D.** Tema desain yang sedang tren

**Kunci: B**

- ✅ **Jika benar:** Trend berubah, tetapi HTML, CSS, JavaScript, dan SQL tetap menjadi fondasi. Karena itu belajar konsep, bukan hanya nama framework.
- ❌ **Jika salah:** Nama framework, versi library, dan tema desain cepat berubah dan bukan fondasi.

### Soal 10 — Kenapa Backend Penting?

Manakah contoh tugas backend pada sistem data siswa?

- **A.** Mengatur warna tombol
- **B.** Menolak NIS duplikat dan memastikan kelas tersedia
- **C.** Menampilkan gambar pada halaman
- **D.** Menyusun teks halaman

**Kunci: B**

- ✅ **Jika benar:** Backend memastikan proses benar dan aman: memvalidasi input, menolak NIS duplikat, memastikan kelas tersedia, lalu menyimpan ke database.
- ❌ **Jika salah:** Warna tombol, gambar, dan teks halaman adalah urusan tampilan (frontend), bukan logika backend.

---

### Soal 11 — Kenapa Backend Penting?

Endpoint API yang dipanggil pada demo form pengiriman data siswa adalah?

- **A.** `GET /api/siswa`
- **B.** `POST /api/create/siswa/post`
- **C.** `PUT /api/siswa/1`
- **D.** `DELETE /api/siswa/1`

**Kunci: B**

- ✅ **Jika benar:** Demo memanggil `POST /api/create/siswa/post` dan menampilkan respons `201 Created` beserta data yang dikirim.
- ❌ **Jika salah:** `GET` untuk mengambil data, `PUT` untuk memperbarui, dan `DELETE` untuk menghapus — tidak sesuai alur menyimpan data baru pada demo.

### Soal 12 — Apa Itu Laravel?

Laravel adalah …

- **A.** Framework PHP untuk membangun aplikasi web
- **B.** Bahasa pemrograman baru
- **C.** Sistem manajemen database
- **D.** Sistem operasi server

**Kunci: A**

- ✅ **Jika benar:** Laravel adalah framework PHP untuk membangun aplikasi web dengan struktur rapi dan tools siap pakai.
- ❌ **Jika salah:** Laravel bukan bahasa pemrograman, database, maupun sistem operasi; ia berjalan di atas PHP.

---

### Soal 13 — Apa Itu Laravel?

Manakah yang termasuk bagian struktur Laravel?

- **A.** Route, controller, model, migration, view Blade
- **B.** Photoshop dan Illustrator
- **C.** Excel dan Word
- **D.** Router wifi dan kabel jaringan

**Kunci: A**

- ✅ **Jika benar:** Struktur Laravel terdiri dari route, controller, model, migration, dan view Blade.
- ❌ **Jika salah:** Opsi lain adalah aplikasi atau perangkat yang tidak berhubungan dengan struktur Laravel.

---

### Soal 14 — Apa Itu Laravel?

ORM (Object-Relational Mapping) bawaan Laravel yang memetakan tabel menjadi object PHP disebut?

- **A.** Eloquent
- **B.** Blade
- **C.** Artisan
- **D.** Sanctum

**Kunci: A**

- ✅ **Jika benar:** Eloquent adalah ORM Laravel yang menerjemahkan tabel dan relasi menjadi object PHP.
- ❌ **Jika salah:** Blade = template engine, Artisan = command line Laravel, dan Sanctum = paket autentikasi API.

### Soal 17 — Laravel 8 di Project Ini

Perintah untuk melihat daftar route pada project Laravel adalah?

- **A.** `php artisan route:list`
- **B.** `php artisan serve`
- **C.** `php artisan test`
- **D.** `php artisan key:generate`

**Kunci: A**

- ✅ **Jika benar:** `php artisan route:list` menampilkan semua route yang terdaftar.
- ❌ **Jika salah:** `serve` menjalankan server, `test` menjalankan pengujian, dan `key:generate` membuat application key.

### Soal 18 — Hubungan Laravel dengan Siswa SMK

Menurut materi, apa manfaat mempelajari Laravel bagi siswa SMK?

- **A.** Langsung menjadi ahli tanpa latihan
- **B.** Mengubah pelajaran database menjadi aplikasi nyata dan membangun portfolio
- **C.** Tidak perlu lagi belajar HTML dan CSS
- **D.** Menghindari penggunaan Git

**Kunci: B**

- ✅ **Jika benar:** Laravel menghubungkan pelajaran database dan HTML dengan aplikasi nyata, melatih logika lewat CRUD, serta membangun portfolio yang bisa didemokan.
- ❌ **Jika salah:** Laravel tidak membuat seseorang langsung ahli, tetap butuh HTML/CSS, dan justru melatih kerja terstruktur dengan Git.

### Soal 19 — Roadmap Belajar Laravel

Pada roadmap belajar di materi, setelah PHP dasar dan SQL, tahap berikutnya adalah?

- **A.** Laravel
- **B.** HTML
- **C.** CSS
- **D.** Desain logo

**Kunci: A**

- ✅ **Jika benar:** Urutan roadmap: HTML → CSS → PHP dasar → SQL → Laravel → validasi/autentikasi/testing → Git, API, dan deployment.
- ❌ **Jika salah:** HTML dan CSS berada di awal roadmap, sedangkan desain logo bukan bagian dari roadmap tersebut.

### Soal 20 — Jenis Pekerjaan

Pekerjaan yang berfokus pada UI responsive, interaksi, dan aksesibilitas disebut?

- **A.** Frontend Developer
- **B.** Backend Developer
- **C.** QA / Software Tester
- **D.** Technical Support

**Kunci: A**

- ✅ **Jika benar:** Frontend Developer membuat UI responsive, interaksi, dan aksesibilitas.
- ❌ **Jika salah:** Backend menangani API dan business logic, QA menguji, dan Technical Support menangani instalasi serta troubleshooting.

### Soal 21 — Portfolio yang Dicari

Manakah yang termasuk isi portfolio yang dicari menurut materi?

- **A.** README berisi masalah, fitur, instalasi, dan teknologi
- **B.** Hanya screenshot tanpa penjelasan
- **C.** Copy-paste kode tanpa memahami isinya
- **D.** Koleksi sertifikat tanpa project nyata

**Kunci: A**

- ✅ **Jika benar:** Portfolio yang baik memuat live demo, README (masalah, fitur, instalasi, teknologi), diagram database, validasi dan test, Git history, serta video demo singkat.
- ❌ **Jika salah:** Screenshot tanpa penjelasan, copy-paste tanpa pemahaman, dan sertifikat tanpa project tidak membuktikan kemampuan.

### Soal 23 — Project 5 Hari

Apa kegiatan utama pada Hari 4 project 5 hari?

- **A.** Menyusun PRD dan merancang tabel
- **B.** Membuat migration, model, dan relasi Eloquent
- **C.** Membuat layout Blade, form, tabel, navigasi, dan CSS responsif
- **D.** Menguji aplikasi dan presentasi

**Kunci: C**

### Soal 24 — Langkah Setelah Slide Ini

Setelah menjalankan project data siswa, langkah berikutnya menurut materi adalah?

- **A.** Langsung pindah ke framework lain
- **B.** Membaca setiap file: route, controller, model, migration, Blade
- **C.** Menghapus repository supaya rapi
- **D.** Berhenti karena project sudah selesai

**Kunci: B**

- ✅ **Jika benar:** Setelah menjalankan project, baca setiap file, tambah satu fitur kecil, catat log, commit ke Git, lalu presentasikan alurnya.
- ❌ **Jika salah:** Pindah framework, menghapus repo, atau berhenti justru menghilangkan kesempatan memahami alur project.

### Soal 25 — Kesimpulan

Manakah kesimpulan yang sesuai dengan materi?

- **A.** Dunia kerja hanya membutuhkan skill teknis
- **B.** Website bukan jalur yang praktis untuk memulai
- **C.** Project nyata, testing, dokumentasi, dan portfolio membuka peluang
- **D.** Fondasi HTML, CSS, dan SQL tidak lagi penting

**Kunci: C**

- ✅ **Jika benar:** Dunia kerja butuh skill teknis dan skill manusia; HTML, CSS, JavaScript, SQL, dan backend adalah fondasi; project nyata, testing, dokumentasi, serta portfolio membuka peluang.
- ❌ **Jika salah:** Opsi lain bertentangan dengan kesimpulan materi yang menekankan fondasi dan bukti kerja nyata.
