Slide 8

Trend Web Development

  • JavaScript tetap sangat luas digunakan; Node.js dan React menjadi teknologi web populer.
  • HTML/CSS tetap fondasi utama antarmuka.
  • SQL tetap penting karena hampir semua aplikasi menyimpan data.
  • Docker, npm, cloud, dan API semakin umum dalam workflow tim.
  • AI membantu coding, tapi review, testing, dan keamanan tetap tanggung jawab developer.

Data teknologi: Stack Overflow Developer Survey 2025

✅
Kesimpulan: Trend berubah, fondasi web tetap dipakai. Belajar konsep, bukan hanya nama framework.
🍽️

Perumpamaan: web development seperti restoran

Frontend = ruang makan dan menu yang dilihat pengunjung. Backend = dapur dan koki yang memproses pesanan. Database = gudang bahan tempat data disimpan. API = pelayan yang menyampaikan pesanan. Docker dan deployment = SOP cabang agar semua restoran berjalan dengan standar yang sama.

Slide 9

Kenapa Backend Penting?

Frontend menampilkan form. Backend memastikan prosesnya benar dan aman.

  • Validasi input dari user.
  • Menyimpan dan mengambil data dari database.
  • Mengatur hak akses.
  • Menyediakan API.
  • Mencatat error dan menjaga performa.
🎓

Contoh sistem siswa

Backend menolak NIS duplikat, memastikan kelas tersedia, lalu menyimpan siswa ke database.

Slide 10

Apa Itu Laravel?

Laravel adalah framework PHP untuk membangun aplikasi web dengan struktur yang rapi dan tools siap pakai.

🧱

Struktur

Route, controller, model, migration, view Blade.

⚡

Produktivitas

Validasi, ORM Eloquent, queue, mail, testing, artisan.

🧰

Ekosistem

Starter kit, Sanctum, Horizon, Reverb, Scout, Forge, Cloud.

🐘
PHP tetap relevan: Laravel memberi jalur terstruktur untuk membuat aplikasi web nyata.

Slide 14

Roadmap Belajar Laravel

  1. HTML semantic dan form.
  2. CSS layout responsive dengan custom properties/design token.
  3. PHP dasar: variable, condition, loop, function, array.
  4. SQL: tabel, primary key, foreign key, query.
  5. Laravel: route, controller, model, migration, Blade.
  6. 🔐Validasi, authentication, authorization, testing.
  7. Git, API, deployment, keamanan.
⏱️
Rutinitas: 30–60 menit per hari, satu konsep kecil, satu commit, satu catatan.

Slide 18

Project 5 Hari: Sistem Input Data Siswa

Target akhir: aplikasi Laravel CRUD siswa dan kelas yang dapat dijalankan, diuji, dan dipresentasikan.

1️⃣

Hari 1 — Rencana

Pahami PRD, siapkan XAMPP dan Laravel, rancang tabel kelas serta siswa.

2️⃣

Hari 2 — Database

Buat migration, model, relasi Eloquent, lalu jalankan database.

3️⃣

Hari 3 — Backend

Buat route dan controller CRUD siswa/kelas, validasi NIS unik dan relasi kelas.

4️⃣

Hari 4 — Tampilan

Buat layout Blade, form, tabel, navigasi, CSS responsif, dan pesan error.

5️⃣

Hari 5 — Uji & Presentasi

Tambahkan test, uji alur manual, rapikan README, catat log, dan presentasikan project.

🎯
Hasil belajar: Project selesai dalam scope kecil, punya fitur CRUD, validasi, testing, dokumentasi, dan siap didemokan.

Ukur kemajuan dari fitur yang selesai dan dapat dijelaskan, bukan jumlah tutorial yang ditonton.
