Latar Belakang

Latar Belakang Project

Saat ini data siswa dan kelas masih dicatat manual di buku atau spreadsheet terpisah. Cara ini lambat, mudah duplikat, dan sulit dipakai saat menyusun laporan.

Karena setiap siswa selalu terhubung ke satu kelas, pencatatan terpisah membuat data cepat tidak sinkron. Sekolah butuh satu tempat yang rapi untuk mencatat, mencari, dan memperbarui data.

Karena itu dibuat aplikasi web sederhana berbasis Laravel untuk mengelola data siswa & kelas secara terpusat, sesuai kebutuhan PRD dan kompetensi yang dipelajari.

💡
Pelajaran: Sebelum menulis kode, pahami dulu masalah nyata dan alasan project ini dibuat.

Step 6 · Tabel Kelas

Migration: Tabel Kelas

Buat file migration lalu isi schema tabel kelas.

Setiap blok code bisa disalin lewat tombol clipboard di pojok kanan.

1. Generate file migration

php artisan make:migration create_kelas_table

2. Copy schema tabel kelas — database/migrations/2026_09_08_000001_create_kelas_table.php

<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up()
    {
        Schema::create('kelas', function (Blueprint $table) {
            $table->id();
            $table->string('nama_kelas')->unique();
            $table->timestamps();
        });
    }

    public function down()
    {
        Schema::dropIfExists('kelas');
    }
};
💡
Pelajaran: nama_kelas dibuat unik agar tidak ada nama kelas yang kembar.

Step 6 · Tabel Siswa

Migration: Tabel Siswa

Buat file migration lalu isi schema tabel siswa, terhubung ke tabel kelas.

Setiap blok code bisa disalin lewat tombol clipboard di pojok kanan.

1. Generate file migration

php artisan make:migration create_siswa_table

2. Copy schema tabel siswa — database/migrations/2026_09_08_000002_create_siswa_table.php

<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up()
    {
        Schema::create('siswa', function (Blueprint $table) {
            $table->id();
            $table->string('nis')->unique();
            $table->string('nama');
            $table->foreignId('kelas_id')
                ->constrained('kelas')->cascadeOnDelete();
            $table->enum('jenis_kelamin', ['L', 'P'])->nullable();
            $table->timestamps();
        });
    }

    public function down()
    {
        Schema::dropIfExists('siswa');
    }
};

3. Jalankan migration

php artisan migrate
php artisan migrate:fresh   # hapus & buat ulang semua tabel (development)
💡
Pelajaran: Migration adalah version control untuk struktur database.

Step 7 · Model Siswa

Model Siswa

Model Siswa punya relasi belongsTo ke Kelas.

Setiap blok code bisa disalin lewat tombol clipboard di pojok kanan.

1. Generate file model

2. Copy code model Siswa — app/Models/Siswa.php

<?php
namespace App\Models;
use Illuminate\Database\Eloquent\Model;

class Siswa extends Model
{
    protected $table = 'siswa';
    protected $fillable = ['nis', 'nama', 'kelas_id', 'jenis_kelamin'];

    public function kelas()
    {
        return $this->belongsTo(Kelas::class);
    }
}

Step 8 · validated()

validated() — Aturan Validasi

Aturan validasi bersama untuk store() dan update(). Baris terakhir menutup class.

private function validated(Request $request, ?Siswa $siswa = null)
{
    return $request->validate([
        'nis' => ['required', 'string', 'max:50', Rule::unique('siswa', 'nis')->ignore($siswa)],
        'nama' => ['required', 'string', 'max:255'],
        'kelas_id' => ['required', 'integer', 'exists:kelas,id'],
        'jenis_kelamin' => ['nullable', Rule::in(['L', 'P'])],
    ]);
}
}

Step 9 · destroy()

destroy() — Hapus Kelas

Menolak hapus jika kelas masih punya siswa; jika kosong, kelas dihapus. Baris terakhir menutup class.

public function destroy(Kelas $kela)
{
    if ($kela->siswa()->exists()) {
        return redirect()->route('kelas.index')
            ->with('error', 'Kelas tidak dapat dihapus karena masih memiliki siswa.');
    }
    $kela->delete();
    return redirect()->route('kelas.index')->with('success', 'Kelas berhasil dihapus.');
}
}
