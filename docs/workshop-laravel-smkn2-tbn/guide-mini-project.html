Membuat Project Sistem Input Data Siswa

Tekan tombol Selanjutnya atau panah keyboard untuk pindah slide.

Step 1

Pahami Kebutuhan Project

  • Kelola data siswa dan data kelas.
  • Setiap siswa terhubung dengan satu kelas.
  • Menerapkan CRUD: Create, Read, Update, Delete.
  • Dibatasi dua tabel sesuai PRD.

Fitur wajib

  • Tambah, lihat, edit, hapus siswa.
  • Tambah dan lihat kelas.
  • Pilih kelas saat input siswa.
  • NIS unik, nama & kelas wajib.

Belum dibuat

  • Login.
  • Nilai & absensi.
  • Upload foto.
  • Search & export CSV.
💡
Pelajaran: PRD membatasi pekerjaan. Jangan langsung menambah fitur di luar kebutuhan.
🧰

Step 2

Siapkan Tools

  • XAMPP 8.2.x (Apache, MySQL, PHP 8.2.x).
  • PHP minimum 7.3.
  • Composer 2.x.
  • Node.js dan npm.
  • Editor kode, Git (opsional).
php --version
composer --version
node --version
npm --version

Start Apache dan MySQL lewat XAMPP Control Panel.

💡
Pelajaran: Pastikan tools siap sebelum debugging kode.
📦

Step 5

Rancang Database dari Relasi

kelas 1 ---- banyak siswa
siswa banyak ---- 1 kelas

Tabel kelas

  • id
  • nama_kelas, unique
  • created_at, updated_at

Tabel siswa

  • id, nis (unique), nama
  • kelas_id FK ke kelas.id
  • jenis_kelamin L/P, nullable
  • created_at, updated_at
💡
Pelajaran: Rancang tabel dan relasi sebelum membuat form atau controller.

Step 6

Buat Migration

  • 2026_09_08_000001_create_kelas_table.php — nama_kelas unik.
  • 2026_09_08_000002_create_siswa_table.php — NIS unik, FK kelas_id, jenis_kelamin nullable, cascadeOnDelete.
php artisan migrate

💡
Pelajaran: Migration adalah version control untuk struktur database.

Step 7

Buat Model dan Relasi Eloquent

  • Kelas — fillable nama_kelas, hasMany(Siswa::class).
  • Siswa — fillable nis, nama, kelas_id, jenis_kelamin; belongsTo(Kelas::class).
$siswa->kelas->nama_kelas;
$kelas->siswa;
💡
Pelajaran: Model menerjemahkan tabel menjadi object PHP. Relasi mencegah query manual berulang.
🎓

Step 8

Buat Controller Siswa

SiswaController memakai pola resource:

  • index — daftar siswa.
  • create / store — form & simpan siswa baru.
  • edit / update — form & perbarui siswa.
  • destroy — hapus siswa.
Siswa::with('kelas')->orderBy('nama')->get();
💡
Pelajaran: Eager loading mengambil nama kelas tanpa query berulang (menghindari N+1).

Step 9

Buat Controller Kelas

  • store — validasi & simpan kelas.
  • destroy — hapus kelas hanya jika belum punya siswa.
💡
Pelajaran: Validasi bisnis tetap diperlukan walaupun database sudah punya foreign key.

Tutorial Code 3

Migration Tabel Siswa

php artisan make:migration create_siswa_table

<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up()
    {
        Schema::create('siswa', function (Blueprint $table) {
            $table->id();
            $table->string('nis')->unique();
            $table->string('nama');
            $table->foreignId('kelas_id')
                ->constrained('kelas')->cascadeOnDelete();
            $table->enum('jenis_kelamin', ['L', 'P'])->nullable();
            $table->timestamps();
        });
    }

    public function down()
    {
        Schema::dropIfExists('siswa');
    }
};

Tutorial Code 7

Controller Siswa

app/Http/Controllers/SiswaController.php

<?php
namespace App\Http\Controllers;

use App\Models\Kelas;
use App\Models\Siswa;
use Illuminate\Http\Request;
use Illuminate\Validation\Rule;

class SiswaController extends Controller
{
    public function index()
    {
        $siswa = Siswa::with('kelas')->orderBy('nama')->get();
        return view('siswa.index', compact('siswa'));
    }

    public function create()
    {
        return view('siswa.create', ['kelas' => Kelas::orderBy('nama_kelas')->get()]);
    }

    public function store(Request $request)
    {
        Siswa::create($this->validated($request));
        return redirect()->route('siswa.index')->with('success', 'Data siswa berhasil ditambahkan.');
    }

    public function edit(Siswa $siswa)
    {
        return view('siswa.edit', ['siswa' => $siswa, 'kelas' => Kelas::orderBy('nama_kelas')->get()]);
    }

    public function update(Request $request, Siswa $siswa)
    {
        $siswa->update($this->validated($request, $siswa));
        return redirect()->route('siswa.index')->with('success', 'Data siswa berhasil diperbarui.');
    }

    public function destroy(Siswa $siswa)
    {
        $siswa->delete();
        return redirect()->route('siswa.index')->with('success', 'Data siswa berhasil dihapus.');
    }

    private function validated(Request $request, ?Siswa $siswa = null)
    {
        return $request->validate([
            'nis' => ['required', 'string', 'max:50', Rule::unique('siswa', 'nis')->ignore($siswa)],
            'nama' => ['required', 'string', 'max:255'],
            'kelas_id' => ['required', 'integer', 'exists:kelas,id'],
            'jenis_kelamin' => ['nullable', Rule::in(['L', 'P'])],
        ]);
    }
}

Tutorial Code 8

Controller Kelas

app/Http/Controllers/KelasController.php

<?php
namespace App\Http\Controllers;

use App\Models\Kelas;
use Illuminate\Http\Request;

class KelasController extends Controller
{
    public function index()
    {
        return view('kelas.index', [
            'kelas' => Kelas::withCount('siswa')->orderBy('nama_kelas')->get(),
        ]);
    }

    public function store(Request $request)
    {
        $request->validate([
            'nama_kelas' => ['required', 'string', 'max:100', 'unique:kelas,nama_kelas'],
        ]);
        Kelas::create($request->only('nama_kelas'));
        return redirect()->route('kelas.index')->with('success', 'Kelas berhasil ditambahkan.');
    }

    public function destroy(Kelas $kela)
    {
        if ($kela->siswa()->exists()) {
            return redirect()->route('kelas.index')
                ->with('error', 'Kelas tidak dapat dihapus karena masih memiliki siswa.');
        }
        $kela->delete();
        return redirect()->route('kelas.index')->with('success', 'Kelas berhasil dihapus.');
    }
}
