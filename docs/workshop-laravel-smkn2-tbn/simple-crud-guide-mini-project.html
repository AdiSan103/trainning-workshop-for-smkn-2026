Latar Belakang

Latar Belakang Project

Data siswa masih dicatat manual di buku atau spreadsheet terpisah. Cara ini lambat, mudah duplikat, dan sulit dipakai saat menyusun laporan.

Karena semua informasi siswa cukup ditampung dalam satu tabel, kita tidak perlu relasi antar tabel. Fokusnya adalah melatih alur CRUD dari awal sampai akhir.

Karena itu dibuat aplikasi web sederhana berbasis Laravel untuk mengelola data siswa secara terpusat, sesuai kebutuhan PRD dan kompetensi yang dipelajari.

💡
Pelajaran: Sebelum menulis kode, pahami dulu masalah nyata dan alasan project ini dibuat.

Step 1

Pahami Kebutuhan Project

  • Kelola data siswa pada satu tabel saja.
  • Menerapkan CRUD: Create, Read, Update, Delete.
  • Tanpa relasi antar tabel, tanpa login.
  • Dibatasi satu tabel sesuai PRD.

Fitur wajib

  • Tambah, lihat, edit, hapus siswa.
  • Daftar siswa berisi semua data.
  • NIS unik, nama & kelas wajib.

Belum dibuat

  • Login.
  • Tabel kelas (relasi).
  • Nilai & absensi.
  • Upload foto.

Step 6 · Tabel Siswa

Migration: Tabel Siswa

Buat file migration lalu isi schema tabel siswa.

Setiap blok code bisa disalin lewat tombol clipboard di pojok kanan.

1. Generate file migration

php artisan make:migration create_siswa_table

2. Copy schema tabel siswa — database/migrations/2026_09_08_000001_create_siswa_table.php

<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up()
    {
        Schema::create('siswa', function (Blueprint $table) {
            $table->id();
            $table->string('nis')->unique();
            $table->string('nama');
            $table->string('kelas');
            $table->enum('jenis_kelamin', ['L', 'P'])->nullable();
            $table->timestamps();
        });
    }

    public function down()
    {
        Schema::dropIfExists('siswa');
    }
};

3. Jalankan migration

php artisan migrate
php artisan migrate:fresh   # hapus & buat ulang semua tabel (development)
💡
Pelajaran: Migration adalah version control untuk struktur database.

Step 8 · validated()

validated() — Aturan Validasi

Aturan validasi bersama untuk store() dan update(). Baris terakhir menutup class.

private function validated(Request $request, ?Siswa $siswa = null)
{
    return $request->validate([
        'nis' => ['required', 'string', 'max:50', Rule::unique('siswa', 'nis')->ignore($siswa)],
        'nama' => ['required', 'string', 'max:255'],
        'kelas' => ['required', 'string', 'max:100'],
        'jenis_kelamin' => ['nullable', Rule::in(['L', 'P'])],
    ]);
}
}
💡
Pelajaran: Rule::unique(...)->ignore($siswa) membuat NIS tetap unik tanpa menolak data miliknya sendiri saat diedit.

Route Siswa

Tujuh route CRUD data siswa: daftar, form tambah, simpan, detail, form edit, perbarui, dan hapus.

Route::delete('siswa/{siswa}', [SiswaController::class, 'destroy'])->name('siswa.destroy');

Fungsi · Siswa Index

Fungsi Tiap Aturan

  • .card — garis atas biru sebagai penanda identitas halaman, plus border-radius & box-shadow agar kartu tampak lebih modern.
  • .page-heading h1::before — garis aksen gradien biru→ungu di kiri judul.
  • letter-spacing: -.01em — judul sedikit lebih rapat dan rapi.
  • border-radius: 99px — mengubah tombol tambah menjadi bentuk pil.
  • .btn-primary:hover — tombol terangkat halus (translateY) saat diarahkan kursor.
  • thead th — header tabel menempel saat daftar di-scroll, dengan latar lebih tegas.
  • tbody tr:nth-child(even) — baris genap diberi warna beda (zebra) agar mudah dibaca.
  • tbody tr:hover — menyorot baris tabel saat kursor mendekat.
  • :focus-visible — outline biru untuk pengguna keyboard, sekaligus aksesibilitas.
  • @media (max-width: 640px) — judul dan tombol menumpuk rapi di layar kecil.

Warna

Biru #1769aa dan ungu #7c3aed dipakai konsisten lewat gradien.

Interaksi

Efek :hover dan :focus-visible memberi umpan balik visual pada tabel dan tombol.
